# Erdos647Necessary: working notes

## Plan
From `h`: for 1 ≤ k < n, τ(n-k) ≤ k+2 (`hA`).
Key bound (`leaf`): if m = d·t with gcd(d,t)=1, e ∣ t, t ≠ e, then τ(m) ≥ τ(d)(τ(e)+1).
gcd(d,t)=1 is shown as gcd(rad d, t mod rad d) = 1 together with d ∣ (rad d)^6.
Prove n ≡ 0 mod 2, 4, 8, 24, 72, 360, 2520 in turn (lemmas `stageN`). In each stage,
split n mod N (refined to mod 16/32/216/5040 where needed) into residues. For each residue
pick k, d (the part of n-k whose exponents are known exactly) and e (the part known only up
to a lower bound) with τ(d)(τ(e)+1) > k+2. The tree was generated by the Python search in
the session scratchpad. One special case, n = 36, is ruled out directly with k=1 (τ(35)=4).
